SourceTube for Windows

1. Extract the ZIP somewhere writable, for example Documents\SourceTube.
2. Copy app\.env.example to app\.env and fill in your credentials.
3. Double-click sourcetube.cmd.
4. Open http://localhost:8787.

Native playback uses the bundled Rust player through mpv/libmpv. Install mpv
for Windows and keep mpv.exe in PATH for low-RAM playback.

No Mac build is included. Use the web client instructions in README.md.
